# AI Usage Report

## Tools Used & Use Cases
- **Gemini (AI Assistant):**
  - **Project Setup:** Generated terminal commands (`mkdir -p`, `touch`) to quickly create the required folder structure and empty files.
  - **Version Control:** Provided the exact terminal commands to initialize the Git repository and link it to GitHub (`git init`, `git branch -M main`, `git push`, etc.).
  - **Styling:** Generated a foundational CSS template to establish the initial layout and design system.
  - **Code Explanation:** Explained specific HTML attributes, particularly how `<form action="#" method="POST" id="contact-form">` functions.
  - **CSS Properties:** Suggested using `object-fit: cover;` to fix image aspect ratios.
  - **Documentation:** Assisted in drafting and structuring the `README.md` file to meet the assignment rubric.

## Benefits & Challenges
- **Benefits:** Using AI drastically sped up the initial project setup and Git configuration, saving time on boilerplate tasks. It also served as an excellent on-demand tutor, instantly explaining HTML tags and CSS properties when I encountered visual bugs (like stretched images).
- **Challenges:** When generating the CSS template, the AI initially provided styles that did not perfectly match my HTML structure. The challenge was manually reviewing the AI's CSS and modifying the class names and layout rules to ensure they applied correctly to my specific sections.

## Learning Outcomes
- **Terminal & Git:** Learned how to efficiently scaffold a web project using command-line tools and how to execute a complete Git workflow to push local code to a remote repository.
- **HTML Forms:** Gained a clear understanding of form attributes, specifically that `action="#"` prevents the page from navigating away and `method="POST"` is the standard for submitting data securely.
- **CSS Image Handling:** Discovered the `object-fit: cover;` property, learning how to force images into uniform dimensions without stretching or distorting them.

## Responsible Use & Modifications
I utilized AI primarily as a tutor and scaffolding tool rather than copying finished work. 
- The terminal and Git commands were modified to include my actual GitHub repository link and appropriate commit messages.
- The CSS template provided by Gemini was manually reviewed, and I adjusted the color variables, spacing, and specific class names to integrate seamlessly with my custom HTML. 
- The code explanations (like the form attributes and `object-fit`) were used strictly to improve my own technical understanding so I could implement the solutions confidently.
