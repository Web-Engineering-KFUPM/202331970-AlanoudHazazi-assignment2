# Personal Portfolio Web Application – Assignment 2

## Project Description
An interactive, responsive personal portfolio website developed for CS coursework. It showcases technical projects, education background, and web engineering practices using modern vanilla HTML5, CSS3, and JavaScript.

## New Features in Assignment 2
- **Dynamic Live Search:** Instant client-side filtering of projects by title or keyword as the user types, complete with empty-state feedback ("No matching projects found").
- **Theme Persistence (`localStorage`):** Remembers user preference for Dark/Light mode across browser sessions and page reloads.
- **Form Validation & Loading State:** Live error checking on form inputs (email formatting, empty inputs) alongside an animated loading indicator and confirmation alert on submit.
- **CSS Animations & Transitions:** Smooth color and layout transitions, interactive hover card transformations, and spinner animations.
